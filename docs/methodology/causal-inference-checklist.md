# 因果推論チェックリスト（report 公開前に全項目に答える）

`methodology-reviewer` はこのリストに沿って `VERDICT` を出す。各 report の末尾に「チェックリスト回答」節を置く。

## A. 問いと事前登録
- [ ] 問い・仮説・主要指標は `design/themes/<theme>.md` に**分析前に**書かれているか。事後に追加した指標は「探索的」と明記したか。
- [ ] 推定したい量（記述的関連 / ATE / ATT / 弾力性 など）を 1 文で書けるか。

## B. データ
- [ ] 全変数の出典・定義・単位・取得日が manifest と report で一致するか。
- [ ] 欠損・系列断絶・定義変更（例: 資産統計の方法変更）を列挙し、補完していないか。
- [ ] サンプル選択（国・年の範囲）の理由と、選択が結果に与える影響を書いたか。

## C. 識別戦略（因果を主張する場合）
- [ ] 戦略を明示: 固定効果 / 差分の差分 / 合成コントロール / IV / RD / イベントスタディ / なし（記述のみ）。
- [ ] 主要な仮定（並行トレンド・外生性・除外制約・SUTVA）を書き、検証できるものは検証したか（例: pre-trend 図）。
- [ ] 逆の因果・同時決定（出生率→成長 など）・省略変数の候補を列挙し、どう対処したか。
- [ ] エコロジカルな誤謬: 国レベルの関係を個人・世帯レベルに読み替えていないか（「フラクタル」の主張はレベル間の比較として明示）。

## D. 推定と不確実性
- [ ] 標準誤差のクラスタ単位（国 など）と理由。
- [ ] 複数検定・仕様の自由度: 試した仕様を全部報告したか（都合の良いものだけ残していないか）。
- [ ] 頑健性: 期間・国サンプル・指標定義を変えても結論が変わらないか。変わるなら書く。

## E. 書き方
- [ ] 「関連」「相関」「〜と整合的」「因果効果」を使い分けているか。
- [ ] 図は軸・単位・出典・n を明記。対数軸は明示。
- [ ] 限界と「この分析では言えないこと」を 1 節設けたか。
- [ ] 再現手順（コマンド列）と使用した mart のスキーマ・行数を書いたか。LLM 構造化を使った列はモデルと schema_version を書いたか。

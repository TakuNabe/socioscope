# H2: 成長「率」と TFR の関連 — 水準との比較と景気後退ショックへの短期反応（2026-10-04, theme: growth-fertility）

## 要約（3〜5 行）
- 国×年パネル（214 経済、1964–2024 年、n=10,576）で、GDP 成長率と TFR の**国内（within）**の関連は小さい。同一サンプル（1990–2024、n=6,664）の二元固定効果で比べると、ln GDP pc の標準化係数 0.053（within-R² 0.003）に対し、成長率ラグ 0–3 はそれぞれ 0.042〜0.050（within-R² 0.002〜0.002、合算 0.006）で、**成長率は水準より弱いとは言えず、どちらも within ではほぼ説明力がない**。H2 前半（「水準より弱い」）は、H1 のプール推定（国間の負の相関、R² 0.60）との対比では成り立つが、国・年 FE の下では水準・成長率とも同程度に弱い。
- 分布ラグ（ΔTFR_t を成長率 t..t−3 に回帰、国 FE）の累積反応は 3 年で **+0.0006 [−0.0003, +0.0015] 出生/女性 per +1 %pt**（成長率 5 %pt の落ち込み ≈ TFR 変化 −0.003、ΔTFR の SD 0.085 の 4%）。方向は順行的（不況で TFR 減）だが CI はゼロを含む。Δ ln TFR と 1990 年以降サンプルではゼロから離れる（+0.0006 [+0.0003, +0.0009]、+0.0013 [+0.0003, +0.0023]）。
- イベントスタディ（成長率 < −2 %、国＋年 FE、端点ビン）: k=0..+4 の係数は −0.004〜−0.009 で CI はゼロを含み、≥+5 ビンのみ −0.020 [−0.030, −0.009]。この ≥+5 ビンは「イベントから遠い後年」をすべて含み、不況を経験した国の長期的な TFR 低下トレンドを拾っている可能性が高い。**端点ビンを外す探索的仕様では符号が逆転**（k=−3, −2 が参照 k=−1 より有意に高く、後期も正）し、形状は仕様に依存する。国内デミーン済みの記述平均では、不況前 3 年（+0.009）から不況後 2 年以降（≈ 0〜−0.003）へ ΔTFR が約 0.01 下がる。
- 結論: 成長率・景気後退と TFR の**短期的な関連は存在するとしても小さく（年あたり 0.005〜0.01 出生/女性、ΔTFR の SD の 1 割程度）**、符号は順行的で H2 後半と「整合的」だが、事前登録した端点ビン仕様と探索的仕様で形が一致しないため**頑健な短期反応とは言えない**。識別戦略は無く、因果効果ではない。

## 方法
識別戦略: **なし**。景気後退は外生ではない（金融危機・紛争・資源価格・政変を含み、出生に直接関わる要因と同時に起きる）。予期（成長鈍化は閾値を超える前年から始まる）と、逆の因果（出生の変化 → 労働供給・需要）も排除できない。以下はすべて**関連**の記述で、「効果」とは読まない。SE はすべて**国（iso3）クラスタ**（同一国内の系列相関）。

1. **(a) 水準 vs 成長率**: 同一サンプルで `tfr ~ x + C(iso3) + C(year)`、x = `ln_gdp` / `g_t` / `g_{t−1}` / `g_{t−2}` / `g_{t−3}` / 4 ラグ同時 / ln GDP ＋ 4 ラグ。比較指標は FWL で国・年ダミーに残差化した x̃, ỹ による**標準化係数** b·sd(x̃)/sd(ỹ) と **within-R²**（不均衡パネルでも厳密）。
2. **(b) 分布ラグ**: `d_tfr ~ g_t + g_{t−1} + g_{t−2} + g_{t−3} + C(iso3)`。累積反応 Σ_{k≤j} b_k の SE は係数の分散共分散行列から。年 FE 入り、Δ ln TFR も併記。
3. **(c) イベントスタディ**: イベント = 成長率 < −2 %（主）。各国×年に「最も近いイベント」との差 k を与え、−3..+5 に端点ビン化（k≤−3 → −3、k≥+5 → +5）、参照 k=−1。`d_tfr ~ Σ_k D_k + C(iso3) + C(year)`。イベントの無い国は全ダミー 0（比較群）。k=−3, −2 は pre-trend の確認。k=0 からの累積和も報告。
4. **(d) 異質性**（事前リスト）: 高所得 vs 非高所得、2000 年未満 vs 以降、産油国除外、小国除外、両方除外。各々で (b) と (c) を再推定。
5. **頑健性**（事前リスト）: 閾値 0 % / −5 %、2020–21 年除外、Δ ln TFR、人口加重 WLS（人口欠損行は除外）、1990 年以降。
6. **記述図**: 2004–2013 と 2016–2024 の各年について、国間の平均・四分位範囲の ΔTFR（回帰ではない）。

仮定（記述として解釈するための）: クラスタ内の相関のみ許容。event time の割当は「最も近いイベント」1 つ（多重イベントの重なりは考慮しない）。乱数は使わない（決定的）。

- 国・年 FE の下では、水準も成長率も TFR の within 変動を **0.3〜0.6% しか説明しない**。成長率の標準化係数（単独 0.04〜0.05）は ln GDP（0.05）と同程度で、ラグ合算の within-R² は ln GDP を上回る。「成長率は水準より弱い」は within の意味では**支持されない**。
- 一方、H1 のプール OLS（国間、R² 0.60、ln GDP の係数 −1.04）と比べれば、成長率の関連ははるかに弱い。H2 前半は「国間の水準差 ≫ 国内の成長率変動」という意味でのみ成り立つ。
- 成長率の符号は正（好況で TFR 高）で、ラグ 1〜3 が同時点より僅かに大きい（受胎→出生の遅れと整合的だが差は小さく、区別できない）。

- 主閾値: pre-trend（k=−3, −2）はゼロと区別できない。k=0..+4 は一貫して負（−0.004〜−0.009）だが各 CI はゼロを含む。k=0 からの累積は +3 で −0.024 [−0.050, +0.001]、+5 で −0.051 [−0.091, −0.010]。
- ≥+5 ビンが最も大きい。これは「不況から 5 年以上経った全ての年」であり、**短期反応ではなく、不況を経験した国（主に非高所得国）の長期的な TFR 低下速度の差**を含む（下の異質性で非高所得のみ −0.026、高所得は −0.001）。

- **探索的・記述**（国内デミーン済み平均 ΔTFR、年 FE なし）: k=−3 +0.0096、−2 +0.0079、−1 +0.0087、0 +0.0023、+1 +0.0047、+2 −0.0024、+3 +0.0003、+4 +0.0031、+5 −0.0029、窓外 −0.0032。不況前 3 年は窓外より ΔTFR が約 0.012 高く（好況期）、不況後 2 年以降は窓外と同水準に戻る。「不況後に ΔTFR が平時より低い」のではなく「不況前の好況期に ΔTFR が高い」と読む方が記述に忠実。

- **分布ラグ**: 累積反応は全変種で −0.0001〜+0.0015（人口加重を除く）。符号は概ね正（順行的）だが、産油国を除くとほぼゼロ、2000 年以降・1990 年以降・2000 年未満・Δ ln TFR では CI がゼロを含まない。**産油国の油価ショック（成長率の大きな変動）が主サンプルの推定にかなり寄与**している。人口加重は中国・インドに支配され不安定（累積 +0.004、CI 幅が 6 倍）。
- **イベントスタディ**: 負の k≥0 係数は非高所得・小国除外で大きく、**高所得国ではすべてゼロ付近**（k=0 +0.001、≥+5 −0.001）。ただし同じサブサンプル（非高所得、小国除外）で **pre-trend k=−3 も有意に負**（−0.015）であり、イベント前から ΔTFR が低い傾向がある → 平行トレンドの前提が満たされず、post 係数を「反応」と読めない。
- 2020–21 年除外で結果は変わらない（年 FE が既に吸収）。1990 年以降では k=+2, +3 が −0.016 [−0.029, −0.005], −0.016 [−0.029, −0.004] と主サンプルより大きい。
- 閾値 −5 % では短期係数が消える。

## 限界・言えないこと
- **因果は言えない**。識別戦略は無い。景気後退は紛争・資源価格・金融危機・政変と同時に起き、それらが出生に直接作用する。イベント前年に減速が始まる予期（探索的仕様で k=−1 が最低）と、逆の因果（出生の減少 → 労働供給や消費への影響）も排除できない。
- **TFR の年次変動は測定上平滑**。WDI の TFR は多くの途上国で UN WPP の推計値（センサス・調査の間を補間、5 年平均を年次化）であり、年単位の景気ショックへの反応が**原理的に記録されにくい**。高所得国（出生登録に基づく）で反応がゼロに近い結果はこれで説明できないが、途上国の推定は系列の滑らかさを反映している可能性がある。期間 TFR のテンポ効果（先送り → 後の反動増）も、ΔTFR の短期プロファイルを打ち消す方向に働く。
- **event-time の割当・端点ビン**: 「最も近いイベント」1 つに割り当て、多重イベントの重なりを無視した。端点ビンは遠い年をすべて含み、不況を経験しやすい国の長期トレンド差を拾う。探索的仕様（端点なし）でプロファイルの符号が逆転したことは、**事前登録した仕様の結果を単独で解釈してはいけない**ことを示す。本レポートは両方を示し、短期反応の主張を保留する。
- **成長率は総額**（一人当たりではない）。人口成長率の高い国では一人当たり成長率が低く、成長率と TFR の関連に人口動態が機械的に入る（TFR 高 → 人口成長 → 総額成長）。これは (a) の正の符号を**上向きにバイアス**しうる。一人当たり成長率は mart に無い（`gdp_pcap_ppp` の対数差分で代替できるが 1990 年以降のみ。本レポートでは行っていない）。
- **極端値**: 成長率の min −64 %、max +150 %（紛争・資源・小国）を winsorize していない。産油国除外で DL 累積がゼロになることは、推定が大きな成長率変動に引っ張られていることを示す。
- **エコロジカルな誤謬**: 国レベルの関連であり、「失業した個人・世帯が出生を先送りする」という個人レベルの主張とは異なる。本レポートは個人・世帯レベルについて何も言わない。日本国内（H3）との「フラクタル」比較も行っていない。
- `income_group` は時間不変（2025 年時点）で、1960 年代に高所得でなかった国も「高所得」に入る。
- 2024 年の値は暫定、2025 年は TFR 欠損。年 FE はサンプル内の国のみで定義される。

# H1c: `data_quality` の向きを正した U 字判定の感度分析（H1 追補、2026-10-05, theme: wealth-population-distribution）

## 要約（3〜5 行）
- H1（`2026-10-04-h1-ushape.md`）の頑健性変種「`data_quality` ∈ {4, 5} を欠損化」は、WID の 0–5 スコアを「高いほど推計・外挿」と誤解していた。H1b と `design/data-sources.md` で**高いほど一次データに近い**ことを確認したので、同じ U 字基準・同じ窓（1950–2024）で向きを正した 3 変種（V-A: q ≤ 1 を欠損化、V-B: q ≤ 2 を欠損化、V-C: q ≥ 4 のみ残す）を 4 系列で再実行した。H1 の数値は変更しない。
- **資産上位 1%**: 国×年の 70% が q0（JPN SAU ARG AUS BRA CHL COL CRI CZE ISR MEX NZL TUR は全年 q0）なので、q ≤ 1 を落とすだけで適格国は **46 → 8**（V-A）、q ≤ 2 で **5**（V-B, V-C とも DEU ESP FRA GBR… の長期一次資料国だけ）。残った国では U 字は **5/8 = 0.63 [0.31, 0.86]**（V-A）、**4/5 = 0.80 [0.38, 0.96]**（V-B, V-C）と過半だが、区間は 0.5 をまたぎ、サンプルは Piketty 系研究の対象国に偏る。H1 の「資産で U 字は少数派（12/46）」は、質の高い年だけでは**支持も反証もできない**（判定不能が 38–41 か国）。
- **所得上位 1%**: V-A で 21/37 = 0.57 [0.41, 0.71]（p = 0.26）、V-B で 20/32 = 0.63 [0.45, 0.77]（p = 0.11）と H1 の 0.48 より上がるが、多数派とは言えない。V-C（q ≥ 4 のみ）では 1980 年以前の q3 年が落ちて谷までの下降が見えなくなり 9/21 = 0.43。「1980 年以降の上昇」は V-A 32/37（0.87）、V-B 29/32（0.91）、V-C **21/21（1.00 [0.85, 1.00]）** と、質の高い年に限るほど強く出る（H1b の観測年のみ 14/15 と同じ向き）。
- H1 の旧変種（4–5 を欠損化: 資産 9/45、所得 15/39）は最良の年を落とした結果で、**向きが逆の参考値**として扱う。正しい向きでは、資産は「判定不能が大半」、所得は「U 字の割合は上がるが過半とは言えず、1980 年以降の上昇はほぼ全国」と読む。
- 日本: 資産は全年 q0 で、どの変種でも年が残らない（判定不能）。所得は 1950–79 年が q4、1980–2024 年が q1 で、V-A/V-B では 2014 年以降が落ち最終年 2013 年（U 字でない、1979 年比 +2.2 pp、2013 年の順位 20/45・17/42）、V-C では 1980 年以降が落ちて不適格。**WID metadata は日本の 1980 年以前を「所得税データの傾向から構築」（imputed）としており、`data_quality` の高低と metadata の construction が日本では食い違う**。すべて記述であり因果は扱わない。

## 問いと仮説
`design/themes/wealth-population-distribution.md` の H1（上位 1%/10% 資産シェアは 1980 年前後を谷として U 字型に上昇している国が多数派）の追補。H1 レポートの限界節に注記した「`data_quality` 変種は向きが逆」を、正しい向きで実際に再計算して置き換える。

推定したい量: H1 と同じ**事前定義の U 字基準を満たす国の割合**（記述的）を、`data_quality` の低い国×年を欠損化したサンプルで再計算したときの値。新しい仮説は立てない。変種 V-A/V-B/V-C と対象 4 系列、図の内容は結果を見る前にスクリプト docstring に列挙した（事前の予想も書いた: 資産は V-A で既に適格国が大きく減る、所得は V-C で 1980 年以前が落ちる）。

## 方法
識別戦略: なし（記述）。H1 の U 字基準・窓・適格性（`a20261004_h1_ushape.Criterion` の `BASE`: 窓 1950–2024、1990 年より前に 3 観測以上かつ 2000 年より後に 3 観測以上、谷 ∈ [1965, 1995]、δ = 1 pp）をそのまま import して使い、系列の年を以下で欠損化してから `classify_all` → `majority_test` / `rise_since_1980_test` を再実行する（行は落とさず値を None にする。補完しない）。

事前列挙の変種（docstring）:
- V0 基準: 全年（= H1 の主結果。照合用）。
- V-A: `data_quality ≤ 1` の国×年を欠損化（弱）。
- V-B: `data_quality ≤ 2` の国×年を欠損化（中。H1b で「q ≤ 2 ⇒ 非観測」が所得で成立）。
- V-C: `data_quality ≥ 4` の国×年だけ残す（強）。

各変種・系列で: 適格 n、U 字の割合（Wilson 95%、片側二項 p は目安）、1980 年（最近傍）以降上昇の割合、V0 から判定が変わった国、日本の判定・1980 年比・最終年の順位（適格なら）。新しい純粋関数 `mask_quality`（V-A/V-B は H1 の `drop_quality` と同じ結果になることをテストで確認）、`quality_matrix`、`quality_counts_by_country` は `tests/test_analysis_h1c.py` で検証。乱数なし（2 回実行で stdout・PNG がバイト一致）。

### 読み方
- **資産**: `data_quality` の低い年を落とすと、適格国が 8（V-A）〜5（V-B/V-C）に激減する。これは資産系列の 70% が q0 であり、q0 以外の年が 1990 年より前に 3 年以上ある国が CHE DEU DNK ESP FRA GBR NLD SWE USA 程度しか無いため。残る国では U 字が過半（5/8、4/5）だが、n が小さく区間は 0.5 をまたぐうえ、これらは長期の遺産税・富裕層資料がある国（Piketty 系研究の対象国）に偏る。H1 の「U 字は少数派」は、質の高い年に限ると**判定不能**であって反証ではない。SWE が V-B で不適格になるのは 1950–78 年が q2 で、落とすと 1990 年より前に q ≥ 3 の年が無いため。
- **所得**: V-A/V-B では不適格になる国（BRA COL CRI ISL LTU LVA MEX SAU SVN、V-B ではさらに EST IDN ISR KOR TUR）が q1–2 中心の国で、H1 で非 U だった国が分母から抜けるため割合が 0.48 → 0.57 → 0.63 と上がる。V-B の 20/32 は H1 の探索的分割「1960 年以前から系列がある国」の 21/33 とほぼ同じ国集合である。V-C（q ≥ 4 のみ）では多くの欧州国で 1980 年以前が q3 のため落ち、谷までの下降が見えなくなって DNK GBR HUN IRL ITA NLD POL PRT SWE ZAF 等が非 U または不適格に変わる（9/21）。一方「1980 年以降の上昇」は V-C で **21/21**（CI 下限 0.85）と、質の高い年だけでは最も強く出る。
- **資産と所得の非対称**: 所得は q ≥ 3 が国×年の 78%、資産は 21%。同じ閾値でも資産では「ほぼ全部落ちる」ので、H1 の資産側の結論はデータの質で層別できない（H1b の「資産には観測年の記述が無い」と同じ帰結）。
- **旧変種との対比**: H1 の「4–5 を欠損化」は資産で USA DNK FRA ESP の一次資料年、所得で AUS CAN NZL USA 等の全年を落としていた。向きを正すと、それらの国はむしろ**残る側**になり、U 字の割合は資産で 0.20 → 0.63–0.80、所得で 0.38 → 0.57–0.63（V-A/V-B）に動く。旧変種の値は参考値として H1 の表に残し、本追補を指す注記に置き換えた。

- 日本の所得系列は **1950–79 年が q4、1980–2013 年が q3 または q1、2014–2024 年が q1**。WID metadata の `method` は 1980 年以前を「所得税データの傾向から構築」（H1b で imputed）としており、`data_quality` の高低と construction が逆向きに見える。どちらを信じるかで日本の「質の高い年」が正反対になるため、日本について `data_quality` ベースの層別は**解釈できない**。H1 の日本の記述（1980 年比 +2.2 pp、順位低下）は V-A/V-B の数値（1979 年比 +2.2 pp、2013 年順位 20/45・17/42）と整合的だが、根拠年の質は確認できない。

## 頑健性
本レポート自体が H1 の頑健性分析であり、変種は V-A/V-B/V-C で全部（事前列挙どおり）。U 字基準のパラメータ（δ、谷の窓、分析窓）は H1 で動かしたので再掲しない。閾値を事後に追加・変更していない（q ≤ 0 のみ除外は H1b の V3 として既報: 資産 5/9、所得 21/46）。

## 限界・言えないこと
- **因果は言えない**（H1 と同じ）。
- **`data_quality` の定義は非公開**。「高いほど一次データに近い」は本データでの経験則で、WID の更新で変わりうる。日本の所得のように metadata の construction と食い違う例があり、スコアが「観測か推計か」を表すとは限らない（ソースの種類や補正の有無を反映している可能性）。
- **資産は層別できない**。q0 以外の年がある国が少なすぎて、質の高い年だけの U 字判定は n = 5–8 の記述に留まる。
- U 字判定が落ちる（V-C 所得）のは、1980 年以前の年が q3 で落ちて「谷までの下降」が見えなくなる構造的帰結であり、U 字が「無い」証拠ではない（H1b と同じ注意）。
- 国レベルの話であり、個人・世帯には読み替えない。46 か国は OECD＋G20 であり WID 全体の多数派ではない。
- 二項検定の p 値と Wilson 区間は国を独立とみなした目安（H1 と同じ）。

# テーマ: 経済成長と出生率の関係（国間・国内のフラクタル構造）

## 問い
1. **国間**: 経済成長率（および所得水準）と出生率（TFR）の関係はどのような形か。時代で変わったか。
2. **国内**: 同じ国（まず日本）で、所得・資産階層と出生率の関係は国間の関係と**同じ形（フラクタル）**か、逆向きか。

## 仮説（事前登録）
- H1: 国間では所得水準と TFR は負の相関（人口転換）。ただし高所得国内では近年 J 字反転の兆候がある。
- H2: 成長「率」と TFR の関係は水準より弱く、ショック（景気後退）への短期反応として現れる。
- H3: 日本国内では所得階層と有配偶率・出生数の関係は正（国間と逆）で、フラクタルではない。
- H5（2026-10-06 追加、文献調査とデータ調査の後・データを見る前に固定）: (a) 家族関連の公的支出は同じ国の中で TFR と正の関連を持つが、その大きさは 2010 年以降の北欧の低下幅を説明できるほど大きくない。(b) 国内の階層勾配は欧州（学歴）でも男性で正であり、女性では北欧で正・南欧／東欧で弱いか負。韓国の新婚夫婦では夫婦所得と有子率は負（共稼ぎ交絡）。(c) 北欧の 2010 年以降の TFR 低下は第 1 子（無子化）が主で、全学歴層で起きている。
- H4（2026-10-05 追加、H1〜H3b の結果を見た**後**に立てた仮説。検証手順は結果を見る前に下記に固定）: 国間の「所得水準 × TFR」の負の勾配は、所得そのものではなく**人口転換の段階**（死亡率・教育・都市化・女性就業）が TFR を決め、所得が段階と相関することで現れる見かけの関係である。したがって (a) 段階指標を揃えると国間の所得勾配は大きく減衰し、(b) 段階を固定した上では所得と TFR の関係は 0 以上（所得効果）で、(c) 国内の所得（資産）階層勾配は国の段階が進むほど負から 0・正へ向かう（勾配自体が段階に依存し、フラクタルではない）。

## 指標
- TFR、合計出生数、年齢別出生率、有配偶率
- 一人当たり GDP（PPP）、GDP 成長率、失業率、女性労働参加率
- 日本国内: 所得階層別の有配偶率・子ども数（国民生活基礎調査・出生動向基本調査の公表集計表）

### H2（成長率・景気後退ショック）の事前登録の詳細 — **実装済み**（2026-10-04、結果を見る前にスクリプト docstring に固定）
データは WDI の `gdp_growth`（`NY.GDP.MKTP.KD.ZG`、1961 年以降）と `tfr`。ラグ・差分は前年の行が存在するときだけ作る（補完しない）。識別戦略は**なし**（景気後退は外生ではない。予期・測定・逆の因果）。結果は関連・「整合的」までで因果効果とは書かない。
- (a) 水準 vs 成長率: 同一サンプル（ln GDP pc と成長率ラグ 0–3 が揃う 1990–2024）で二元 FE（国＋年、国クラスタ SE）の `tfr ~ ln_gdp` と `tfr ~ growth_{t-k}`（k=0..3 単独・合算）を、FWL で残差化した標準化係数と within-R² で比較する。成長率の方が小さければ「水準より弱い」と整合的。
- (b) 分布ラグ: `ΔTFR_t ~ growth_t..growth_{t-3}` ＋国 FE（国クラスタ SE）。累積反応 Σ b_k を分散共分散から区間推定し図示。年 FE 入りも併記。
- (c) イベントスタディ: 景気後退 = 成長率 < −2 %（主。< 0 %, < −5 % は頑健性）、同一国で前イベントから 5 年以上空ける（昇順の貪欲法）。event time は最も近いイベントとの差、−3..+5 に端点ビン化、参照 k=−1。`ΔTFR`（主）と `Δ ln TFR`、国＋年 FE、国クラスタ SE。k=−3,−2 は pre-trend 確認。
- (d) 異質性（事前リスト）: WB 高所得 vs 非高所得（時間不変分類）、観測年 2000 年未満 vs 以降、産油国除外、人口 100 万人未満の行除外（H1 の `OIL_STATES`/`SMALL_POP` を import）。
- 頑健性（事前リスト）: 閾値、2020–21 年除外、Δ ln TFR、人口加重 WLS、1990 年以降サンプル。2008–09・2020 は年 FE に吸収されるので、国間平均 ΔTFR の推移を**記述図**として別掲。
- 事後に追加（探索的、report で明記）: 端点ビン化しない窓（−3..+5 の外を 0）版のイベントスタディと、event time 別の国内デミーン済み平均 ΔTFR の記述表。

2. パネル回帰: 国固定効果・年固定効果、ラグ付き成長率。標準誤差はクラスタ。

## 既知の落とし穴
- 成長率と TFR のどちらにも長期トレンドがあり、見せかけの相関が出やすい → 固定効果・差分で処理。
- 「所得階層別出生率」は日本では直接の公表統計が乏しく、世帯所得×子ども数などの代理指標になる。定義のズレを report に書く。

### H4（段階 vs 所得: 国間の負の勾配は見かけか）— 事前登録（2026-10-05）
**実装済み**（2026-10-05、`reports/2026-10-05-h4-stage-vs-gdp.md`）。判定結果: (a) 整合的、(b) 主仕様で整合的、(c) 事前基準では不支持（転換完了層のみ勾配ゼロ）、(d) 部分的。
**動機**: H1 で国間 −1.04・国内（within）≈ 0、H3/H3b で日本国内は正。「所得 → 出生率」が一枚の因果なら国間でも国内でも同符号になるはずで、符号が逆転するのは、国間では所得と相関する別の構造（人口転換の段階）が TFR を決めているからではないか、というユーザー提案の仮説。経済学的には Becker の数量–質トレードオフ・時間の機会費用（所得効果 vs 代替効果）、Galor–Weil の統一成長理論、Doepke–Hannusch–Kindermann–Tertilt (2023) が整理した「高所得国で所得–出生率の関係が負から正に転じた」観察に対応する。**注意**: この仮説は H1〜H3b の結果を見た後に立てたものである。以下の推定量・サンプル・判定基準は、追加データ（下記）を見る**前**に固定した（DHS API は到達性確認のため Afghanistan 2015・Albania 2008 の 10 行だけ目視した）。

**追加データ**
- WDI 段階指標（`worldbank.INDICATORS` に追加、mart `growth_fertility_panel` の列）: `u5_mortality` = `SH.DYN.MORT`（5 歳未満死亡率、出生千対。人口転換の標準的マーカー）、`fem_sec_enrol` = `SE.SEC.ENRR.FE`（女子中等教育総就学率 %）、`urban_share` = `SP.URB.TOTL.IN.ZS`（都市人口 %）、`fem_lfp` = `SL.TLF.CACT.FE.ZS`（女性労働参加率 %、ILO 推計、1990 年以降）、`life_exp` = `SP.DYN.LE00.IN`（出生時平均余命）。
- DHS Program Indicator Data API（`api.dhsprogram.com`、キー不要、引用必須。`design/data-sources.md`）: 指標 `FE_FRTR_W_TFR`（調査前 3 年の TFR、15–49 歳）× 特性 `Wealth quintile`（Lowest/Second/Middle/Fourth/Highest。**資産ベースの国内相対順位**であり所得額ではない）。全調査（DHS・MIS・AIS、取得後の実数: 1990–2025、77 か国・313 調査。countries エンドポイントは 92 件だがデータがあるのは 77 か国）。mart `marts/dhs_tfr_by_wealth_quintile`（long: iso3, country, survey_id, survey_year, survey_type, quintile 1..5, quintile_label, value, ci_low, ci_high, denominator_weighted, source）。ISO3 は `/rest/dhs/countries` の `ISO3_CountryCode` で付ける（無ければ行を落とし skipped に残す）。

**推定量（スクリプト `analysis/a20261005_h4_stage_vs_gdp.py` に固定）**
- (a) **減衰**: H1 と同じフレーム（1990–2024、tfr・gdp 観測）を 5 指標 listwise で絞った**同一サンプル**で、国間（pooled OLS ＋ 年 FE、国クラスタ SE）の `tfr ~ ln_gdp` と `tfr ~ ln_gdp + u5_mortality + fem_sec_enrol + urban_share + fem_lfp + life_exp` を比較する。主判定は `ln_gdp` 係数の比（調整後/調整前）。段階指標は 1 本ずつ加えた版も出す（どの指標が減衰を担うか）。**判定**: 比 ≤ 0.5 で「H4(a) と整合的」、0.5–0.8 で「部分的」、> 0.8 で「不支持」。ただし段階指標は所得の**媒介**でもありうるため、減衰は「所得の国間関連は段階を経由または段階に交絡している」までしか言えず、「所得は無関係」とは言わない。
- (b) **段階固定の所得係数**: 同一サンプルで二元 FE（国＋年）`tfr ~ ln_gdp + 段階指標`。**判定**: `ln_gdp` の 95% CI 下限 ≥ 0 なら「H4(b) と整合的（所得効果 ≥ 0）」、CI が 0 を含めば「判定不能」、上限 < 0 なら「不支持」。段階指標の within 係数も報告する（これは H4 の主張の一部ではなく記述）。
- (c) **段階層別の国間勾配（Simpson 型分解）**: 5 歳未満死亡率で層を事前固定（< 10, 10–25, 25–50, 50–100, ≥ 100 /千）。層内の pooled＋年 FE 勾配 `tfr ~ ln_gdp` を層ごとに推定し、全体の勾配と並べる。**TFR で層別しない**（結果変数での層別は同語反復）。**判定**: 全層で層内勾配が全体勾配の半分以下（絶対値）なら整合的。層内勾配が全体と同程度に負なら不支持。
- (d) **国内勾配の段階依存（フラクタル検定の本体、DHS）**: 調査ごとに 5 五分位が揃う行から `gap = TFR_Q5 − TFR_Q1`（主）、`slope` = 五分位順位 1..5 への OLS 傾き、`ratio = Q5/Q1`（補助）を作る。調査年の WDI（`ln_gdp`、`u5_mortality`、`fem_sec_enrol`）を同じ iso3×year で結合（補完しない。該当年欠損は落とす）。モデル: `gap ~ ln_gdp`（pooled、国クラスタ SE）、`gap ~ ln_gdp + C(iso3)`（同一国の複数調査内）、年トレンド調整版 `+ survey_year`。段階代理を `u5_mortality`（符号は逆向きを予測）、`fem_sec_enrol` に替えた版。**予測**: `∂gap/∂ln_gdp > 0`（豊かな段階ほど負の勾配が浅い）。**判定**: pooled と国 FE の両方で CI 下限 > 0 なら「整合的」、片方なら「部分的」、どちらも 0 を含むか負なら「不支持」。記述: gap < 0 の調査の割合、gap ≥ 0 の調査の一覧。
- (e) **日本との接続（記述のみ）**: H3/H3b の日本の勾配（男性有配偶率 +0.17〜0.20、児童世帯割合 +0.12）は指標が違うため (d) の回帰には入れない。(d) の図に「DHS 調査国の段階の範囲」を示し、日本（ln GDP ≈ 10.6、U5MR ≈ 2）が範囲外の延長上にあることを図示する。「延長したら正になる」とは**言わない**（外挿）。

**サンプル・頑健性（事前リスト）**: (a)(b)(c) は H1 の `OIL_STATES` 除外・人口 100 万未満除外・2020–24 除外・`fem_sec_enrol` を外した 4 指標版（就学率は欠損が多い）。(d) は SurveyType = DHS のみ／全タイプ、`slope`・`ratio`、1 国 1 調査（最新）に絞った版、人口加重なし（主）／加重。

**言えないこと（事前に明記）**: 識別戦略なし。段階指標は所得の媒介か交絡かを区別できない（Baron–Kenny 型の「媒介分析」はしない）。DHS の富裕五分位は国内の相対資産順位で、日本の個人所得階級とは定義が異なる。TFR は女性ベース、日本側は男性有配偶率。DHS 対象国は低・中所得国に偏り、高所得国の国内勾配は本データでは観測できない。

### H5（韓国・欧州の国内階層勾配と「手厚い政策でも回復しない北欧」）— 事前登録（2026-10-06）
**問い（ユーザー）**: 韓国・欧州の所得階層別データで「国の中では所得が高いほど結婚・出産」が日本特有かを確かめたい。特にフィンランドは手厚い家族政策にもかかわらず出生率が回復しない。根本的な因果構造は何か。

**先に書いておくこと**: 公開集計データでは因果構造は識別できない。本テーマでできるのは、文献が提示する説明のうち集計データで反証可能な命題を事前に固定し、整合・不整合を記述することまで。文献（2026-10-06 調査、report に一覧）の暫定像: 北欧の低下は第 1 子の減少（無子化）が主で全学歴層に及ぶ（Hellstrand et al. 2021 Demography; Comolli et al. 2021 EJP; Statistics Finland 2024）。家族政策（保育・育休）の因果効果は実証されているが、効果量は 2010 年代の低下幅より一桁小さい（Bergsvik, Fauske & Hart 2021 PDR のレビュー; Rindfuss et al. 2010）。北欧の男性では学歴・所得が高いほど子どもが多く、女性の勾配は負から正へ転じた（Jalovaara et al. 2019 EJP）。残差は「不確実性の知覚」「理想子ども数の低下」（Golovina et al. 2024 ESR）など選好側に求められている。

**データ調査の結論（2026-10-06）**: 欧州の「所得階級別」出生・有配偶の API 公開表は北欧 4 統計局にも Eurostat にも無く、機械取得できる階層軸は**学歴（ISCED 2011）**。韓国は KOSIS OpenAPI がキー必須のため、国家データ処の報道資料 PDF（KOGL 第 1 類型）から新婚夫婦統計の表を読む。

**推定量（`analysis/a20261006_h5_europe_korea_policy.py` に固定）**
- (a) **政策 × TFR**: SOCX 家族支出（合計／現金／現物）と WDI TFR の iso3×year パネル（1980–2021、OECD 38）。(a1) 二元 FE（国＋年、国クラスタ SE）`tfr ~ family_total` と `tfr ~ cash + inkind`、同時と 3 年ラグ。(a2) 「北欧パラドックス」の直接検定: 国ごとに ΔTFR(2010→2021) を、2010 年の支出水準と Δ支出(2010→2021) に回帰（横断、n ≈ 38）。(a3) 分解: FIN/SWE/NOR/DNK/KOR/JPN について、(a1) の within 係数 × 各国の Δ支出 を「政策で説明できる ΔTFR」とし、実際の ΔTFR と並べる。**判定**: (a1) の within 係数が正で CI が 0 を含まなければ「政策は関連あり」。(a3) で説明できる分が実際の低下の 1/4 未満なら「H5(a)（効果はあっても低下幅を説明しない）と整合的」、1/2 以上なら「不支持」。
- (b) **国内の階層勾配**: 欧州 2021 センサス、性 × 25–59 歳の 5 歳階級 × 学歴 3 群の有配偶率（法律婚＋登録パートナー ÷ 不詳を除く総数）。国ごとに年齢 FE 付き加重 OLS（重み = 群の人数）で学歴順位（0,1,2）の勾配を推定。**判定**: 男性で勾配が正の国が 31 か国中 25 以上なら「H5(b) 男性と整合的」。女性は北欧 5 か国（FI SE NO DK IS）で正、南欧（IT ES PT GR）で負または 0 を予測し、符号表で記述する。日本は H3b の男性の所得勾配（+0.17）を符号のみ併記（軸が違う）。韓国: 新婚夫婦の所得区間別有子率の ln 所得勾配（加重 OLS）を年ごとに出し、符号を記述（共稼ぎ交絡のため判定に使わない）。
- (c) **北欧低下の解剖**: (c1) 出生順位別 TFR の 2010 → 最新年の変化を順位別に分解し、第 1 子の寄与率 = ΔTFR_1 / ΔTFR_total。**判定**: 北欧 5 か国すべてで寄与率 ≥ 0.5 なら整合的。比較国も併記。(c2) 学歴別 TFR（北欧 4）の 2010 → 最新年の変化。**判定**: 3 学歴群すべてで低下していれば「全層で低下」と整合的。ED0-2 の変化幅が最大かを記述（分母が LFS 標本のため CI は出さず、群の人口が 20 千人未満のセルは除外）。
- 頑健性（事前リスト）: (a1) 1995 年以降サンプル、北欧 5 か国除外、韓国・日本除外、人口加重。(a2) 2010→2019（コロナ前）。(b) 年齢 30–49 に限定、学歴 2 群（ED5-8 vs それ以外）。(c1) 2008 起点、2019 終点。

**言えないこと（事前）**: 識別戦略なし。家族支出は内生（出生率が下がると子ども 1 人あたり支出比率が変わる、支出の %GDP は景気で動く）。学歴は所得の代理であり日本の所得勾配と同じ軸ではない。センサスの配偶関係は法律婚のみで、北欧の同棲を含まない（有配偶率を過小評価）。韓国の表は新婚 5 年以内の初婚夫婦に限られ、共稼ぎと所得が同時決定。学歴別 TFR は分母が標本（LFS）の近似。出生順位 UNK の扱い（比例配分せず、UNK を除いた順位のみで寄与率を出す）。
